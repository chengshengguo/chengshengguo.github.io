🟢 小汤｜《约翰·汤普森简易钢琴教程》John Thompson's Easiest Piano Course · 1–8 册

原版社：美国 Willis Music｜国内版：上海音乐出版社（彩版 / 扫码音频版）｜定位：零基础启蒙，图文多、进度慢，4–6 岁幼童 / 成人零基础
册识谱与乐理技术训练代表小曲
1高/低音谱号、中央 C、全/二分/四分音符非连奏手型、断奏、二指起步《请弹吧》《爷爷的大钟》
2八分音符、附点、G 五指位连奏萌芽、旋律+伴奏分工《火车》《海军工兵》
3F 位、两手交叉、同音连线、f/p双音（3 度）、跳音、音阶初现《古老的曲调》《农民舞曲》
4升降号（F/G 大调）、切分、十六分音符音阶双手、踏板初用、乐句呼吸《牛仔之歌》《假日之歌》
5D/A 大调、6/8 拍、装饰音雏形三连音、分解和弦、小奏鸣曲感接近大汤 1 难度
📌 国内常跳过 6–8 册直接转大汤 1。每册结尾的"技巧复习页"+"书写作业"（写音符、画拍号）是识谱地基，别跳过。谱面基本配伴奏谱，可以和老师/爸妈四手联弹 🎵

🔵 大汤｜《约翰·汤普森现代钢琴教程》John Thompson's Modern Course for the Piano · 1–5 册

定位：小汤之后 / 或 6 岁以上直接上。按音乐史顺序串古典小品，第一册就讲音阶、和弦转位、十六分音符，进度比小汤快。大汤 2 起可加 599 + 哈农；大汤 5 ≈ 考级 7–8 级乐曲难度。
册技术 / 乐理新点代表曲目（国内版常见）
1音阶指法（C/G/D/F）、和弦转位、十六分音符、踏板初用《春之歌》《浪漫曲》《练习曲》
2复调感（两手独立旋律）、降号调、圆舞曲节奏《在教堂》《比尔的山羊》、小巴赫片段
3三连音、装饰音（倚音/波音）、琶音、双降布格缪勒《阿拉伯风》《清澈的溪水》混入
4快速跑动、左手琶音伴奏、中段转调、长乐句克列门蒂小奏鸣曲 Op.36 出现
5多声部、踏板换踩、复杂装饰音、奏鸣曲式小快板肖邦/舒曼简化改编、海顿小曲
💡 大汤 3 起建议同步加 599 后半 + 巴赫初级钢琴曲集，不然两手各弹各的会懵。
⚠️ 小汤 vs 大汤：两套是独立线，不是简单的"小→大"升级。4–6 岁零基础→小汤 1；6–8 岁/成人零基础→可直接大汤 1，或 小汤 1–2 速通后转大汤 1。

🟤 车尔尼系列Carl Czerny（1791–1857，奥地利，贝多芬的学生）

车尔尼不是"弹完"而是"挑着弹"——老师会挑号；每首标了速度要求（♩=多少），达标才算过，不然"糊过去"没用。299 起可配克拉莫《60 首》。
代号完整中文名作品号定位衔接节点

849《钢琴流畅练习曲》Op.849中级过渡，30 条，训练跑动流畅599 弹完 → 849
299《钢琴快速练习曲》Op.299中高级，40 条，左右手独立、颗粒性849 弹完 → 299

（亦作《钢琴练习曲 50 首》）		Op.740高级，50 条，速度+力度+均匀度299 弹完 → 740

599 内部 7 类练习逻辑（100 条）

1–10纯识谱 + 固定五指位，非连音
11–18五指独立性 + 均匀性，连奏/重音记号
19–26拇指移位（穿指/跨指）关键期，拇指要松弛主动
27–31音域超八度，注意高八度记号
32 起低音谱表正式进入
36 起升/降号出现（F/G/D 大调），别漏看临时变音
61–100音阶、琶音、双音、装饰音综合
📌 装饰音小专题：第 73 条=回音，第 74 条=颤音，第 83 条=倚音，第 95 条=波音——可单独抽出来练。

849 / 299 / 740 核心目标

849跑动"流起来"：乐句连贯 + 速度恒定。技术标签：左右手快速音阶/琶音交替、阿尔贝蒂低音、轮指。♩=100 以上才算过。
299手指独立性 + 颗粒性 + 速度（♩=120–160）。技术标签：双手八度、重复音、跨越大跳、复节奏（3 对 2）、震音。业余考级 8–10 级分水岭。
740音乐会级技术储备。技术标签：双音音阶、三度六度平行、八度断奏、快速琶音、装饰音炫技。弹完可接肖邦练习曲 Op.10/25。

🤲 哈农｜《哈农钢琴练指法》Charles-Louis Hanon（法）· Le Pianiste Virtuose · 1873，60 条

分三部分。大汤 2–3 册起可进，手指力量弱要更早。每天 10–15 分钟，开头热身用（手没开弹哈农没意义）。
部分条号练什么重点
第一部分1–20五指独立性，1–5 指均匀发力每天 1–2 条，慢练，手腕不僵
第二部分21–43音阶 / 琶音 / 属七减七预备20–31 是黄金段，接 599 后半正好
第三部分44–60八度、颤音、重复音、手腕柔顺51 条专攻八度，手小可晚点进
📌 变奏练法（避免枯燥）：原速 → 附点节奏（长-短/短-长）→ 断奏 → 强-弱力度变化。每条先单手后合手，指法严格锁死，肌肉记忆一次定型。低龄手小可《孩子们的哈农》起步。

🎼 乐曲文献与进阶弹"作品"才算会弹琴——技术之后走向音乐

技术练习解决"手指能不能弹出来"，这一组解决"弹出来像不像音乐"。通常在 740 前后、或同步穿插进入。

📐 钢琴小百科（术语速查）

翻谱子遇到看不懂的记号，先来这查。
连奏 Legato音与音连贯不断开，谱上弧线（连音线）标记
断奏 / 跳音 Staccato音短促、离键快，小圆点（·）或短横线（▽）
非连奏 Non-legato不连也不跳，独立清晰，初学手型常用
踏板右=延音（最常用）；中=持音；左=柔音（弱音）
音阶 / 琶音手指跑动基石；属七 / 减七是和声预备
阿尔贝蒂低音左手把和弦音"低-高-中-高"分解的固定伴奏型
装饰音倚音（小斜线，落重音）/ 波音（﹋）/ 颤音（tr，快速交替）/ 回音（∞，绕一圈）
穿指 / 跨指拇指从其他指下穿过（上行）/ 手指从拇指上跨过（下行），音阶流畅关键

✅ 一页速记（贴琴边）

主线：小汤 1–5 → 大汤 1–2 → 哈农 + 599 → 大汤 3 + 849 → 大汤 4–5 + 299 → 740 → 巴赫 / 小奏鸣曲 / 肖邦 / 李斯特
支线（按需穿插）：拜厄、布格缪勒 Op.100（25 首）、莱蒙 Op.37、克拉莫 60
每日基本功：哈农 10–15 分钟热身（慢→原速→变节奏），车尔尼挑号达标速度才算过
三大易错点：升降号 · 低音谱表 · 踏板

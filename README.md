# Mickey的星空学习乐园 🌌

一个面向小学生（准三年级）的太空主题学习网站，纯静态 HTML/CSS/JS，无需构建，可直接用 GitHub Pages 部署或本地打开。

## 主要内容

- **天文科普** (`astronomy.html`)：从太阳系一路讲到银河系、仙女座、拉尼亚凯亚超星系团，一直到整个可观测宇宙。
- **太阳系模型** (`solar-system.html`)：可交互的行星公转动画，点击星球查看资料。
- **英语学习** (`english/`)：覆盖小学阶段的单词卡（按年级/主题）、常用句型与听力测验，点一下即可听发音（Web Speech API），进度存于浏览器本地数据库。
- **口算闯关** (`math.html`)：加、减、乘混合练习，屏上数字键盘，计时计分。
- **语文天地** (`chinese/`)：覆盖小学阶段的必背古诗词 + 常用成语，带拼音与朗读，进度存于浏览器本地数据库。
- **五子棋** (`gomoku.html`)：人机 / 双人对战。
- **数独** (`sudoku/`)：三难度自动出题、实时校验。
- **记忆训练** (`memory.html`)：翻牌配对小游戏。
- **暑假学习计划** (`learn_plan/index.html`)：每日作息安排。

首页 `index.html` 汇总所有入口。

## 特点

- 深空主题、动态星空背景，界面美观。
- 针对 **iPad / 触控设备**优化：大按钮、屏上键盘、导航可横滑。
- 语音发音依赖浏览器内置语音，离线时功能仍可用。

## 本地预览

```bash
python -m http.server 8000
# 浏览器打开 http://localhost:8000/
```

## 部署

直接推送到 GitHub 仓库的 `main` 分支，启用 GitHub Pages 即可（仓库根目录即为站点根）。
